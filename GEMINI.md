# Project: ezhook

This is a [Next.js](https://nextjs.org) application bootstrapped with `create-next-app`.

## Tech Stack

- **Framework:** Next.js 16.2.6 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Library:** React 19

## Building and Running

The following scripts are available in `package.json`:

- `npm run dev` / `pnpm dev`: Starts the development server at [http://localhost:3000](http://localhost:3000).
- `npm run build` / `pnpm build`: Builds the application for production.
- `npm run start` / `pnpm start`: Starts the production server.
- `npm run lint` / `pnpm lint`: Runs ESLint.

## Development Conventions

- **Routing:** Uses the Next.js App Router located in the `app/` directory.
- **Styling:** Tailwind CSS is used for styling.
- **Linting:** ESLint is configured for linting (`eslint.config.mjs`).
